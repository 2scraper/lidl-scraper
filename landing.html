Open-source scraper for lidl.com (Lidl US) product search and weekly deals. Three engines, one documented output schema — price, unit price, discount, brand, and which store/zip a price reflects. Point it at 2Captcha's Scraping Browser API over CDP when you need proxies, fingerprints, and captcha solving bundled — not by default.

Before you scrape: check Lidl's own site and the Lidl Plus app for anything a formal integration or public feed already covers your use case. This scraper is for everything outside that.
Read this before you rely on it: this project's own build tooling could reach lidl.com's robots.txt (wide open) and homepage cleanly, but every deeper page it tried came back 404 to a plain, non-browser fetch — most likely because those routes are client-rendered, not active blocking. The URL scheme is confirmed real; the exact selectors, embedded-data shape, and pagination model are documented best-effort guesses pending a real, browser-rendered capture. The architecture (exit codes, output schema, dedupe, all three engines) is real and tested. Full details in the README — read it first.

Risk management

Infrastructure, when you want it

CAPTCHA SOLVING

Broad detection, solves only when a page is actually gated — never just because a widget is present. Over --cdp-endpoint, wired into Captcha.setAutoSolve: detect, submit, solve, inject, all inside 2Captcha's own session.

SCRAPING BROWSER API

A remote browser session over CDP with its own proxy, fingerprint, and captcha auto-solve already bundled — one --cdp-endpoint flag.

FINGERPRINTS

Optional: pin a specific OS/browser/country fingerprint via the 2Captcha Fingerprint API for a locally-launched browser.

PROXIES

2captcha.com/proxy credentials in .env — rotated automatically, with per-exit failure tracking and masked logs.

Get started

# clone, install, configure
git clone https://github.com/2scraper/lidl-scraper.git
cd lidl-scraper && pip install -r requirements-playwright.txt && playwright install chromium
cp .env.example .env # optional — not required for a local-first run

# a product search
python3 playwright_scraper.py --query "whole milk" --format json --out lidl_results.json

# or a full lidl.com URL directly
python3 playwright_scraper.py --url "https://www.lidl.com/search/products/milk"
